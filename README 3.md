# Data Analytics & Visualization

Demonstrates CSV validation, duplicate removal, numeric/date conversion, calculated revenue, exploratory summaries, and a monthly trend chart with Python and Pandas.

## Run
`pip install -r requirements.txt` then `python main.py`

Outputs are saved to `outputs/`. Import `outputs/cleaned_sales.csv` into Power BI and add KPI cards, monthly revenue, revenue by category, and region/category slicers.

The included data is synthetic demo data, not a real company's data or internship outcome. Replace it with a dataset you are allowed to use before drawing real-world conclusions.
